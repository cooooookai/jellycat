🕹️ 游戏厅开张了！

小房间右下角金币上面多了一个 🎮（右键菜单里也有「🎮 游戏厅…」）。点一台机器叫 TA 来玩，TA 点「来！」就开始。两个人都要在线。

**🎨 你画我猜**
- 一个人画，另一个人看着笔画一笔一笔出来，随时打字猜。90 秒，过一半会送一个字的提示。猜中了换人画。
- 每次给 4 个词选（日常 / 有梗 / 我们俩），不喜欢就「🎲 再随机 4 个」。
- 「💌 给 TA 出题」：写下只有你们俩懂的梗，TA 画的时候会抽到。

**💣 拆弹**
- 一个人拆（看得到炸弹，没有说明书），一个人看说明书（看不到炸弹）。开着微信电话一边说一边拆。
- 每颗炸弹 3 个模块：剪线、按钮、符号、迷宫里随机抽。5 分钟，错 3 次就炸。拆完换人。

**✊ 决定权**
- 猜拳：三局两胜，两边都出完才同时亮出来。可以先写好赌什么。
- 转盘：两个人看到同一个转盘转到同一格。吃什么、谁去找谁、今晚看什么、小惩罚，选项都能改。

每个游戏每天第一次赢 / 猜中 +1～3 金币。

**其他**
- 右键菜单里「发消息…」「叫 TA 开会…」点了没反应的问题修好了。

**更新方法：** 下载 `JellyCat-mac-arm64.zip` → 解压 → 拖进「应用程序」替换 → 终端运行 `xattr -cr /Applications/JellyCat.app`。这次浏览器插件不用动。金币和买过的东西都不会丢。
