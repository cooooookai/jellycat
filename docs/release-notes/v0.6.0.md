## v0.6.0 · 小卖部开张 🪙🎃

**新：小卖部和金币**
- 金币两个人一起用：每人每天上线 +10，两人当天都上线再 +10，每天每种行动 / 状态第一次 +1～3
- 开张礼：100 金币
- 点房间右下角的金币按钮打开小卖部：家具、墙和地、装饰、🎃 万圣节套装，一共 56 件
- 点一件东西，小房间里先预览，喜欢再买；买了两个人的房间都会换上
- 同一位置的东西互相替换，装饰位每个位置只放一件，不会互相挡住

**也在这个版本里（v0.5）**
- 五个时段的房间：清晨 / 白天 / 黄昏 / 夜晚 / 深夜（右键 → 房间时间可以手动选）
- 双击电视一起看 B 站：谁先播放满 3 秒，对方自动跟到同一个视频、同一个进度
- 猫粮和小碗：把猫粮袋拖到自己的碗里 = 我去吃饭了；点一下自己或碗 = 吃完了
- 抽屉里的硅胶棒：拖到水母身上开始按摩，点水母加速，点小猫冒舒服表情，再点抽屉复原
- 新状态：剪映、微信
- 拖到屏幕左边 / 右边收起来，两只从边上探出半个脑袋
- 收到消息有一声很轻的"咕嘟"

**更新方法**
1. 下载 `JellyCat-mac-arm64.zip`（Intel 芯片下 x64），解压后替换「应用程序」里的 JellyCat，然后在终端运行一次 `xattr -cr /Applications/JellyCat.app`
2. Chrome 插件：下载 `JellyCat-chrome-extension.zip`，解压覆盖原来的 extension 文件夹，在 `chrome://extensions` 里点一下刷新
3. 两个人都更新后，金币和买的东西会自动合并同步
