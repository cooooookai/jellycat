## v0.5.0 · 房间里能玩了 🐈‍⬛🪼

- **五个时段的房间**：清晨 / 白天 / 黄昏 / 夜晚 / 深夜，跟着真实时间自动切换（右键菜单也能手动选）
- **双击电视一起看 B 站**：两边 Chrome 都打开 B 站，谁先播放满 3 秒，对方自动跟到同一个视频、同一个进度
- **猫粮和小碗**：把猫粮袋拖到自己的碗里 = 我去吃饭了；点一下自己或碗 = 吃完了
- **抽屉里的硅胶棒**：拖到水母身上开始按摩，点水母加速，点小猫冒舒服表情，再点抽屉复原
- **新状态**：剪映剪视频、回微信
- **收到屏幕边缘**：拖到左边或右边，两只从屏幕边上探出半个脑袋
- 收到消息会有很轻的"咕嘟"一声
- 修复：两个人同时操作房间时，状态不会互相覆盖

**更新方法**：下载新的 zip 替换「应用程序」里的 JellyCat；Chrome 插件要重新下载 `JellyCat-chrome-extension.zip`，解压覆盖原来的文件夹，然后在 `chrome://extensions` 里点一下刷新。
