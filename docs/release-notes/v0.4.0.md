**Mac 安装：**
```
curl -fsSL https://raw.githubusercontent.com/cooooookai/jellycat/main/scripts/install-mac.sh | bash
```
或者下载下面的 zip（M 芯片选 arm64，Intel 选 x64），访达里双击解压、拖进「应用程序」，再在终端运行一次 `xattr -cr /Applications/JellyCat.app`。
